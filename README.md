# Retail Transaction Data Cleaning

## Project Overview
This project focuses on identifying and addressing data quality issues in a retail transaction dataset as part of my Data Analyst Internship at SWYNEX Technologies.

## Dataset
- Total records: 12,575
- Total columns: 11

## Data Quality Findings
- Missing values: 7,229 cells across five columns.
- Exact duplicate rows: 0 found.
- Inconsistent labels: No obvious inconsistencies observed in Category, Payment Method, Location, and Item.
- Data types: Number formats were applied to Quantity, Price Per Unit, and Total Spent. Transaction Date was formatted as a date.

## Missing Values
Missing values were left unchanged where the correct values could not be reliably determined. No values were invented.

## Tools Used
Microsoft Excel

## Outcome
The dataset was reviewed for data quality issues, formatted, and documented for further analysis.
